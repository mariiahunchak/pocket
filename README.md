# Trade Stats Overlay — G-Class v5

A flat, compact G-Class-inspired trading journal overlay.

Features:
- orange/black visual treatment to separate it from the blue trading UI;
- WIN and LOSS controls positioned over the door/body area;
- circular WINRATE gauge near the rear wheel;
- automatic best-effort synchronization with the visible selected asset;
- manual pair selector and sync button;
- per-pair WIN/LOSS and result history;
- draggable widget;
- local Chrome storage.

The widget does not click trading controls, place/close trades, read balance, use private APIs, or intercept network traffic. Automatic pair synchronization reads the visible asset name from the page.
